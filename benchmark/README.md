# Benchmark pair lists

Pair lists used in the RiboSeek paper (chain keys are `<pdb_id>_<author chain id>`).

- `hardneg_11170_pairs.tsv` — the 11,170-pair length-matched hard-negative classification benchmark (8,170 same-family positives, 3,000 different-family negatives).
- `geometric_fidelity_1732_pairs.tsv` — the 1,732 benchmark pairs with both chains between 30 and 500 nt used for the geometric-fidelity comparison, with the US-align TM-score (mean of the two length normalisations) for each pair.
